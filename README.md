# FluxScript - Analizador Léxico

Proyecto de compiladores en C# (.NET SDK).

## Requisitos previos
- Tener instalado [.NET SDK](https://dotnet.microsoft.com/download) compatible con el proyecto.
- Visual Studio Code con la extensión oficial de C#.

## ¿Cómo ejecutar el proyecto?
1. Abrir la terminal en la carpeta raíz del proyecto (`Ctrl + Ñ`).
2. Ejecutar el siguiente comando:
   dotnet run
